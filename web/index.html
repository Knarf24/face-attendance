🎓 Face-based Class Attendance

Stop wasting class time on roll call. Snap the classroom and the app counts the faces, recognises each student and marks the register. Faces it doesn't know yet can be named on the spot.

🐍 Written in Python (OpenCV + NumPy), running right here in your browser with Pyodide.

🔒 Privacy: photos and face data never leave this device. The class list and register are kept only in this browser's storage. Use Download backup to move them, and Delete everything to wipe them. Ask for consent before enrolling anyone's face.

4. Quick setup: build the class list from a few photos

No need to photograph each student. Upload 2 to 10 class photos and the app groups the faces by person without knowing any names (unsupervised clustering). Type a name under each group to add that student.

How it works

  1. Face detection and counting: OpenCV's YuNet detector finds every face in the photo and counts them.
  2. Face fingerprint: each face is lined up by its eyes, nose and mouth and turned into 128 numbers by the SFace recognition network. Photos of the same person give similar numbers.
  3. Recognition: each face is matched to the closest enrolled student (cosine similarity), and each student can only be matched once per photo. Unknown faces are shown in orange so you can name them.
  4. Grouping: for quick setup, faces from several photos are grouped by person with a DBSCAN-style clustering, so you only type each name once.
  5. Attendance tracker: the register keeps who was present on each date, the attendance rate and a CSV export.

All of this is Python (attendance.py and register.py) running in your browser through Pyodide. See the code on GitHub.
